# SCOPE FUNCTIONS

- Hay cinco funciones en la biblioteca estándar de Kotlin que se designan como funciones de ámbito (scope functions):

    - with()
    - run()
    - let()
    - also()
    - apply()

- Cada una de ellas es una función de orden superior que normalmente se llama con una lambda, que introduce una nueva declaración scope &rarr; el objetivo de esta función scope es tomar un objeto existente (llamado objeto de contexto 2) y representarlo de una manera particular dentro de ese nuevo scope.
